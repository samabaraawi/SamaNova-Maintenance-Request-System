# SamaNova Maintenance Request System

A web-based maintenance request and ticket management system developed using PHP, MySQL, HTML, and CSS.

## Features

- User login and authentication
- Maintenance request submission
- Ticket management
- Ticket assignment
- Request status tracking
- Search and filtering
- Image upload support
- Role-based functionality
- MySQL database integration

## Technologies

- PHP
- MySQL
- HTML
- CSS
- PDO
- XAMPP
- phpMyAdmin

## Database

The repository includes the SQL database file required to create the project database and tables.
